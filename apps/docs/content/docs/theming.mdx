---
title: Theming
description: How to customize colors, typography, and tokens.
---

intention/ui uses CSS custom properties (variables) for theming, compatible with Tailwind CSS v4's `@theme` directive.

## Default tokens

```css
@theme {
  --color-intent-primary: oklch(0.6 0.2 250);
  --color-intent-secondary: oklch(0.8 0.1 250);
  --color-intent-muted: oklch(0.95 0.02 250);
  --color-agent-thinking: oklch(0.7 0.15 60);
  --color-agent-success: oklch(0.7 0.2 145);
  --color-agent-error: oklch(0.65 0.25 25);
}
```

## Dark mode

All components use Tailwind's `dark:` variant. Enable dark mode in your root layout by toggling the `dark` class on `<html>`.

## Custom theme

Override any token in your `globals.css`:

```css
@import 'tailwindcss';

@theme {
  /* Your brand primary */
  --color-intent-primary: oklch(0.55 0.22 300);
}
```
