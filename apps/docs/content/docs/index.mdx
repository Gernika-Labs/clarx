Clarx is a three-part system for building interfaces where meaning drives implementation.

## The three layers

**Philosophy** — A framework for thinking about UI as communication. Components express what things mean, not just how they look. Semantic intent is more durable than visual recipes.

**Reference implementation** — Copyable components that demonstrate the philosophy in code. `Badge`, `Button`, `Alert`, `Text`, and a set of AI-native primitives built for streaming, tool calls, and agent state. You own the source.

**AI rules layer** — Portable instructions for AI tools. Drop a `CLAUDE.md` or Cursor rules file into your repo and your AI assistant starts generating semantic, system-consistent UI instead of inventing patterns from scratch.

Each layer is independently useful. Teams can adopt the philosophy without replacing their component library. They can adopt the AI rules without adopting the components. Or they can use all three together.
