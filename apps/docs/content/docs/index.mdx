## What is intention/ui?

intention/ui is a component library and design system built for AI applications.
Unlike traditional UI libraries, every component here is designed around **user intent** —
the idea that AI interfaces are fundamentally different from form-based UIs.

Conversations are not forms. Responses stream. Actions are probabilistic. Errors are recoverable.

## Design principles

**Intention over instruction** — Components communicate what a user is trying to accomplish,
not the mechanics of how.

**Conversational by default** — Every component is aware of context and conversation state.

**AI-native states** — Loading, streaming, thinking, tool calls, and errors are first-class states,
not afterthoughts.

**Copy, don't install** — Like shadcn/ui, you own the components. Copy the source, modify it, ship it.
